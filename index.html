Jason InBody Local Sync

这是个人自用的数据归档工具说明页。工具在用户自己的 Windows 电脑上读取 InBody 测量，并保存到用户自己的私有 Google Drive。本网站不接收、展示或存储测量数据和凭据。

What the utility does

Jason InBody Local Sync is a personal Windows utility that retrieves the owner's InBody measurement records through the account's data interface and archives them to the owner's private Google Drive. It is an independent personal project, not an official InBody or Google product.

The local utility preserves raw measurement records and a separate set of confirmed core fields. It detects repeat measurements so that repeated runs do not create another production copy. Windows scheduled tasks may run the utility after sign-in and once each day.

Why it requests Google Drive access

The utility uses Google's drive.file permission to create archive files and read back files created by, or explicitly selected for, this utility. It does not request access to every file in the Google account. Google describes this permission as allowing viewing, editing, creating and deleting specific files used with the app; normal archive operation preserves existing raw records and stops on content conflicts.

Where the information goes

InBody account → the owner's Windows computer → selected private Google Drive archive folders. Raw and core-field files remain separate. Authentication credentials are kept in Windows Credential Manager; they are not placed in archive files, public source, or this website.

This website provides documentation only. It has no login form, upload form, measurement viewer, analytics scripts, or health-data service. It does not generate health reports, diagnoses or treatment recommendations.
